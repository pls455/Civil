# Phase 0 - Technical Validation

## SQLite على Android

القرار: استخدام SQLite عبر طبقة Dart `sqflite`، مع تخزين محلي داخل مساحة التطبيق الخاصة.

التطبيق لا يدعم ملفات Microsoft Access أو MDB/ACCDB. مصدر البيانات المدعوم هو ملف SQLite صالح يختاره المستخدم من الجهاز.

## استيراد قاعدة البيانات

- اختيار ملف SQLite بامتداد مدعوم مثل `.sqlite` أو `.db` أو `.sqlite3`.
- التحقق من وجود الملف وإمكانية فتحه.
- تنفيذ `PRAGMA integrity_check` قبل اعتماد الملف.
- نسخ الملف إلى ملف مؤقت داخل Application Documents Directory.
- فحص النسخة المؤقتة مرة أخرى.
- تبديل النسخة التشغيلية بعد نجاح الفحوصات، مع إبقاء الملف الأصلي دون تعديل.
- عند فشل الفحص يجب إظهار الخطأ وعدم إعلان نجاح مصطنع.

## Schema والبيانات

يجب اكتشاف الجداول والأعمدة والأنواع من SQLite الفعلية، دون إنشاء سجلات وهمية أو افتراض مخطط ثابت غير موجود في المصدر.

التحويل أو التطبيع لا يُنفذ إلا عند وجود حاجة واضحة في طبقة العرض أو البحث، مع الحفاظ على البيانات الأصلية وعدم الادعاء بأن أي حقل موجود إذا لم يكن موجودًا فعليًا.

## Unicode والعربية

SQLite يدعم تخزين النصوص بصيغة Unicode. يجب اختبار عرض النص العربي والبحث فيه على قاعدة SQLite فعلية، مع تجنب تسجيل بيانات المواطنين في logs.

## البحث والعرض

تستخدم طبقة Dart استعلامات parameterized queries، وpagination عند عرض مجموعات كبيرة، ولا يُفترض تحميل جميع السجلات إلى الذاكرة دفعة واحدة.

## الملفات الكبيرة

المصدر يبقى منفصلًا عن قاعدة التشغيل. تُستخدم نسخة مؤقتة وفحوصات سلامة قبل اعتماد القاعدة التشغيلية. يجب اختبار الأداء والمساحة المتاحة على جهاز Android فعلي بدل اعتبار حدود الحجم ضمانًا عامًا.

## قيود معروفة

- ملفات MDB/Access غير مدعومة.
- قاعدة SQLite المشفرة أو التي تعتمد على امتدادات SQLite غير المتاحة قد لا تُفتح.
- بعض خصائص SQLite أو المخططات غير المعتادة قد تحتاج معالجة خاصة بعد فحص قاعدة فعلية.
- حجم 2-4 GB يحتاج مساحة مؤقتة كبيرة وأداء الجهاز يختلف.
- أكبر من 4 GB مرفوض في المنتج الحالي.
- لا يمكن اعتبار الاستيراد ناجحًا إلا بعد اختبار ملف SQLite حقيقي غير حساس على جهاز Android فعلي.

## شرط الصدق

لا يوجد استيراد وهمي: التطبيق يعتمد على ملف SQLite الذي يختاره المستخدم، ويفحصه قبل اعتماده، ويعرض الخطأ عند الفشل بدل إظهار نجاح مصطنع.
